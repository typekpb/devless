---
name: clean-code
description: >
  Enforce clean code practices: small focused functions, descriptive naming,
  early returns, and concise implementations. Trigger when writing or reviewing
  application code. Do not trigger for test code or infrastructure.
---

- Write small, focused functions with a single responsibility
- Use descriptive names for variables, functions, and classes
- Avoid deep nesting; prefer early returns
- Keep functions under 30 lines where possible
