# GitHub Operations

## Available Tools

### get_issue
Fetch issue details including title, body, state, and comments.
```
get_issue(issue_number=123)
```

### post_comment
Post a comment on an issue or PR.
```
post_comment(issue_number=123, body="🚀 Working on this...")
```

### create_pull_request
Create a new PR.
```
create_pull_request(
    title="Fix: Address issue #123",
    body="Closes #123\n\n## Changes\n- Fixed the bug",
    head_branch="issue-123",
    base_branch="main"
)
```

### get_pull_request
Get PR details including branch and review comments.
```
get_pull_request(pr_number=456)
```

## Comment Conventions

Use these emojis for status updates:
- 🚀 Starting work
- ✅ Completed successfully
- 📝 Addressing feedback
- 🔄 Fixing CI
- 🤔 Need clarification
- ⚠️ Error encountered

## PR Body Template

```markdown
Closes #{issue_number}

## Changes
- List of changes made

## Testing
- How changes were tested

Generated by Devless 🤖
```
